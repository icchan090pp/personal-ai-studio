# DeeL Pyess

独自の画像・動画モデルを育てるローカルアプリ。Windowsは専用ウィンドウ、Linuxはブラウザで操作できます。スマートフォン接続はソース版で利用します。
初期検証版です。**100件の製品試験を5回連続で実行**し、全件合格しました。検証スクリプトとJUnit記録を同梱します。
CUDA実機・大型基盤モデルによるGPU学習／生成品質・個人のWindows実機でのGPU機能は未検証です。Windowsセットアップと基本起動はWindows CIで確認しました。

## v0.1.7：学習済みの画風から、関連画像も使って育てる

「おすすめ設定 → アニメ風」で、学習済みのDreamShaper 8とCPU用の設定・学習指示を選べます。VTuber風・水彩イラスト・写真風の設定も用意しました。VTuber風はアバター表現の設定です。30億枚の学習や全作品・全VTuberの網羅を実施・保証するものではありません。DreamShaper 8のCPU学習はRAM 16GB以上が目安です。画風をゼロから学び直す必要はなく、3枚以上のお手本で自分好みに追加学習できます。最適な設定や品質を保証するものではなく、学習前後の比較を使って調整してください。

「関連画像／関連動画を自動で探し、一緒に学習する」を有効にすると、投稿した画像・動画の内容・画風をBLIPとCLIPでPC内解析し、Wikimedia Commonsで関連画像を検索します。解析モデルは初回に約1.6GBを取得。画像そのものは送信せず、画像から得た検索語を送信します。1回最大3件（設定で1〜5件）を追加し、選択したモデルの実際のLoRA学習に使います。既存の完成モデルを出発点にした継続学習にも対応します。動画では複数フレームの見た目を比較し、実際の短いクリップを映像LoRA学習に使います。動きの一致は保証しません。収集動画の音声は学習に使わず、動画生成時の音声はKokoroなど別モデルで合成します。

類似度の基準・重複・出典を確認し、追加した画像は画面に表示します。元の投稿画像を検索の手がかりにし続け、追加画像は元画像以下の枚数・半分の学習重みで使います。「次の学習から除外」で不要な候補を外せます。検索が失敗した場合や候補がない場合はその旨を表示し、元の画像で学習します。無限に収集・学習を繰り返す機能ではありません。完成済みの版は保持します。

Think・Researchは、画像・動画共通の学習チャットから選びます。Thinkは現在のデータ件数・基盤・前回設定・PCメモリをもとに、ローカルgpt-ossが改善案を考えます。Researchは公式の学習ガイドとWikimedia Commonsの素材情報を取得し、出典付きの学習案を提案します。Ollamaとgpt-ossを別途導入してください。資料の取得に失敗した場合は画面に表示します。提案を確認して学習指示の下書きへ入れ、編集・保存してから学習を実行します。相談だけで重みは更新しません。

## 機能

- Tiny-SD・Small-SDのCPU画像LoRA、SD 1.5・DreamShaper 8のCUDA画像LoRA、CogVideoX-5b-I2V動画LoRAと生成。実験用の短い効果音・環境音モデルの学習／動画への付加
- エクスプローラー・フォルダ投稿、グルーピング、指定サイト内収集、Wikimedia Commons検索、出典保存
- 画像は通常・半教師ありBLIP・スタイル・RWR・生成テスト・写し学習。動画／音声は説明付き通常・写し・スタイル学習
- 学習チャットと生成チャットを分離し、モデルごとの履歴を保存
- 初期ユーザールールは空。歯車から共通生成プロンプトを設定・リセット
- 画像／動画ともノーマル20、パワー35、エクセレント（深考）50、ウルトラ（レベル200）200ステップの生成プリセット
- 指定サイズ2100×2050・720p〜4KのPNG／MP4書き出し。高解像度は生成後のLanczos拡大と余白調整
- 実測の損失・勾配・学習重みL2を棒グラフ表示。8つのAI開発実践コースと実験ノート

## Windowsへのインストール・更新

[Releases](https://github.com/icchan090pp/personal-ai-studio/releases) から `DeeL-Pyess-Setup-v0.1.7-Windows-x64.exe` を取得して実行してください。
Windows 10/11・64bit用、Python同梱です。既存のDeeL Pyessを終了し、同じ保存先へ上書き更新できます。
デスクトップの「DeeL Pyess」で起動し、「このPCのAI機能をセットアップ」を実行します。
投稿データ・完成モデルは `%LOCALAPPDATA%\DeeL Pyess\data`、診断ログは同フォルダのstartup.logです。
アンインストールでもデータを保持します。EXEは未署名です。

Windows版はWebView2の専用画面で起動します。通常のブラウザタブを開く必要はありません。
表示エンジンはMicrosoft署名を確認した導入プログラムで準備します。初回はネット接続が必要です。
アプリ右上の「更新」で最新版を確認・取得できます。公式リリースのSHA256を検証した後、
インストールの確認画面を表示します。取得・検証が失敗した場合は現在のアプリを変更しません。
動作中の学習・生成・収集がある間は更新できません。設定画面や更新画面もアプリ内にあります。

### 一般のノートPC向け（v0.1.3）

NVIDIA CUDA、Windows DirectML（AMD/Intelなど）、CPUを区別して診断します。
AMD/IntelはCUDAを使用できません。DirectMLは独立環境に導入し、CUDA/CPU用のPyTorchを上書きしません。
「作品をつくる」で「Tiny-SD / 軽量画像」を選ぶと、256pxの画像を生成して指定サイズへ拡大します。
GPUの演算非対応・メモリ不足時はCPUで再試行し、使用した環境を結果に記録します。
失敗したGPU処理は記録し、次回からCPUを優先します。「再診断する」でGPUの再試行を許可できます。
明示的にCPUを選択してセットアップした場合は、軽量画像をCPUで生成する設定を保持します。
初回セットアップは数GBのダウンロード、Tiny-SDの重みは約1.3GBです。RAM 8GB以上を目安としてください。
Tiny-SD・Small-SDの画像LoRA学習と学習後の生成はCPUを使います。学習画面で基盤モデルを選び、3枚以上の画像を投稿してください。まず30ステップ・ランク4で試し、完成モデルの版を選んで継続学習できます。各版は保持されます。Tiny-SDはRAM 8GB、Small-SDは12GB以上が目安です。AnimateDiffの短い動画はCPU・RAM 16GB以上が目安です。SD 1.5・DreamShaper 8のCUDA設定とCogVideoXは十分なVRAMを持つCUDA GPUが必要です。アニメ・イラスト用DreamShaper 8のCPU設定はRAM 16GB以上が目安です。
日本語音声と声質特徴抽出はCPUでも利用できます。CPUでは処理に時間がかかります。

### Linux・開発者向けソース版

ソースZIPを展開し、Python 3.12/3.13で `./install.sh`、`./start.sh` を実行します。
AI機能は仮想環境で `python -m studio.setup_runtime --backend cpu`、NVIDIAは `--backend cuda` を指定できます。
日本語音声・声質の追加は `--voice`。Windowsのソース版はInstall-Windows.bat/Start-Windows.batを利用できます。
スマートフォン用はソース版の `Start-Phone.bat`／`./start-phone.sh` を実行し、同じ信頼できるWi-Fiの接続URLを開きます。

## モデルと環境

画像の学習基盤：Tiny-SD・Small-SD・DreamShaper 8アニメ／イラスト（CPU）、SD 1.5・DreamShaper 8（CUDA）。
動画の学習基盤：AnimateDiff v1.5-2 + DreamShaper 8（CPU）、`THUDM/CogVideoX-5b-I2V`（CUDA）。モデル重みはZIPに含まず、初回に配布元から取得します。
それぞれのモデルライセンス・アクセス条件が適用されます。
CPUの目安：Tiny-SD RAM8GB、Small-SD RAM12GB、AnimateDiff RAM16GB以上。CUDA画像学習はVRAM16GB、CogVideoXの生成は16〜24GB、学習は48〜80GB VRAM・ホストRAM32GB以上が目安です。実際の必要量は機器・モデル・設定・他のアプリの使用量で変わります。

[Stability Matrix Releases](https://github.com/LykosAI/StabilityMatrix/releases) はモデル管理アプリの配布元です。
DeeL Pyessは独立アプリとして、管理フォルダにあるSD 1.5 `.safetensors` を読み込みます。
Windows PowerShellでは `$env:STUDIO_CHECKPOINT="C:\Models\SD15.safetensors"`、
Linuxでは `STUDIO_CHECKPOINT=/path/to/SD15.safetensors ./start.sh`。SDXL／Flux／SD2は対象外です。
画像LoRAはDiffusers形式とKohya形式、動画LoRAは選択したAnimateDiffまたはCogVideoXのDiffusers形式を出力します。

実験用の音声学習はゼロから学ぶ小型の波形拡散モデルです。短い効果音の実験用で、自然な会話・声の再現・高品質音楽は対象外。
学習と生成に同じ説明文を使う条件ID方式で、文章の意味理解や映像との音声同期はしません。
RWRは報酬重み付き回帰で、PPO／DDPOではありません。深考は生成ステップの多いプリセットです。
ユーザールールのリセットは共通プロンプトを空にする機能で、基盤モデルの性質は消せません。

## 動画とエージェントの育成

「動画モデル」でAnimateDiffを選び、3本以上の動画を投稿します。256px・4フレームを順序を保って学習し、時間方向と空間方向のattentionへLoRAを最適化します。初期設定は10ステップ・ランク4。完成モデルを学習の出発点に選ぶと続きを育て、別の版として保存します。生成は256px・16フレーム・8fps（約2秒）、720p〜4Kは拡大出力です。CPU処理は数分〜数十分以上かかる場合があります。

生成画面で完成モデルを選び、Kokoroと読み上げる日本語を指定すると音付きMP4を作れます。映像モデルを解放してから音声を合成します。長い音声では映像をループし、ナレーションを切らずに収録します。映像と音声を同時生成するモデルではなく、リップシンクには対応していません。

「エージェント」はOpenAI gpt-oss-20b/120bの指示・知識・お手本を保存し、推論時に反映します。重みの追加学習ではありません。版を選んで応答を試し、評価と修正回答から次の版を作れます。基盤だけの応答との比較と、育成プロフィールのJSON出力に対応。外部操作やコマンドは自動実行しません。

[Ollama](https://ollama.com/download/windows)を別途導入し、`ollama pull gpt-oss:20b` を実行してください。20bはRAM16GB以上、120bは約80GB以上が目安で、他のアプリの使用量によっては不足します。画像・動画ジョブとエージェント推論は同時実行を避けます。CPUでは応答が数分以上かかる場合があります。

## 開発と検証

```bash
bash scripts/cloud-environment.sh setup
bash scripts/cloud-environment.sh verify
```

5回の各実行で、ちょうど100件・失敗0・エラー0・スキップ0をJUnitで検証します。
CPU上の実際の小型SD／CogVideoX／音声ネットワークで、最適化・保存・読み込み・生成を試験。
PNG／4K MP4／AAC音声付加、HTTP API、PC／モバイルの実ブラウザ操作と配布サイトを確認します。
実基盤モデルのGPU動作と品質は別の実機検証が必要です。失敗を隠す代替生成・架空の学習成功はありません。

Linuxで実行権限がない場合：`chmod +x install.sh start.sh start-phone.sh` を実行してください。

v0.1.2では、生成専用の公開モデル4種類（SDXL、SSD-1B、PixArt Sigma、LTX-Video）、
ローカルOllama経由のOpenAI gpt-oss-20b/120b学習相談、ウルトラ（画像・動画200ステップ）、
データを保持する学習停止・リセットを追加しました。追加4モデルのLoRA学習は未対応です。
公開モデルの実サイズGPU生成は本CPU開発環境では未検証です。エージェントを含む実モデルの確認範囲は、公開版の検証レポートに記録します。

音声生成にAudioLDM2 Large（非商用の効果音）とKokoro 82M（日本語読み上げ）を追加。
OpenVoice V2で参照音声の声質特徴を取り込み、速度・高さの対応指示を保存して読み上げへ反映。
動画投稿とサイト収集から音声を抽出し、音声・声質・動画学習へ利用できます。
Windows版の音声付きセットアップ、またはLinux `./install.sh --gpu --voice` で追加音声ライブラリを導入します。
声質の取り込みは特徴抽出で、モデル全体の追加学習ではありません。再現度はモデルと録音によって変わります。

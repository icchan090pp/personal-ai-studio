# DeeL Pyess v0.1.5 — Tiny-SDを見つけやすく

最初の画面に「Tiny-SD / 軽量画像」と「Tiny-SDで画像をつくる」ボタンを追加しました。
ボタンを押すと生成画面へ移動してTiny-SDを選択します。保存先がなければ作業プロジェクトを作成し、既存の保存先があればそのまま使います。音声画面からも画像生成へ切り替わります。

上部の「モデルを選択」は、生成モデルの一覧と混同しやすいため「作業プロジェクトを選択」へ変更しました。
作成ダイアログも「新しいプロジェクト」に統一。Tiny-SDなどの公開モデルで追加学習が必要だと誤解させる案内を修正しました。

v0.1.4をお使いの方は、右上の「更新」→「最新版を確認する」→「更新版を取得する」から更新できます。
新規インストールには `DeeL-Pyess-Setup-v0.1.5-Windows-x64.exe` を使用します。保存済みのデータは保持します。

Tiny-SDの軽量画像はCPU・対応するDirectML/CUDA GPUを使用し、256pxで生成後に指定サイズへ拡大します。
初回に追加ライブラリと約1.3GBのモデルを取得します。RAM 8GB以上が目安です。
Tiny-SDは生成用で、画像LoRA学習・動画・大型モデルは引き続き十分なVRAMを備えたNVIDIA CUDA GPUが必要です。
全GPUの実機動作・生成品質を保証するものではありません。EXEは未署名の検証版です。

# DeeL Pyess v0.1.6 — 画像・動画・エージェントを選び、自分のモデルを育てる

従来は画像学習がSD 1.5固定・CUDA必須で、AMD・Intel搭載PCでは育成を開始できませんでした。
学習画面の「育てる基盤モデル」にTiny-SD・Small-SD・SD 1.5・DreamShaper 8を追加しました。
Tiny-SD・Small-SDはCPUで実際にLoRAを最適化・保存し、その重みを使って生成します。

「学習の出発点」で完成モデルを選ぶと、かんたん・写し・スタイルなどの方法で続きを育てられます。
各学習は別の版として保存し、以前の完成モデルを保持します。
画像4基盤は、画像投稿・学習指示・6つの学習方法・継続学習・版の選択を共通の操作で使います。
「育成前後を比べて生成」は、同じプロンプト・シード・ステップで基盤と学習後の作品を2枚生成し、並べて表示します。
好みの作品の評価を次の学習へ反映できます。違いが改善かどうかは、作品を見て判断してください。「このモデルで生成する」または生成画面の完成モデル欄で使用する版を選べます。
基盤のIDと固定リビジョンを保存し、異なる基盤のLoRAを誤って混ぜないよう検証します。

ノートPC向けの初期設定は256px・30ステップ・ランク4です。まず動作と傾向を確かめ、画像・説明・継続学習で調整してください。
CPU学習には時間がかかります。Tiny-SDはRAM 8GB、Small-SDは12GB以上が目安です。
SD 1.5・DreamShaper 8の画像学習とCogVideoXはNVIDIA CUDA GPUが必要で、必要条件を画面に表示します。
メモリ不足・モデル取得失敗・学習値の異常には対処方法を表示し、投稿画像と完成モデルは保持します。

実公開ウェイトでTiny-SD・Small-SDのCPU学習→保存→継続学習→生成を検証。
Windows公開工程にも、同梱Pythonによる実Tiny-SD CPU学習・重み再読込・生成の試験を追加しています。
実AMD GPUでのDirectML学習を提供する変更ではありません。生成品質はデータと設定によって変わります。

「画像モデル」「動画モデル」「エージェント」の育成項目を追加しました。
動画はAnimateDiff + DreamShaper 8をCPUでLoRA学習でき、完成版から短い映像を生成できます。RAM16GB以上、初期設定は10ステップ・ランク4。標準生成は256px・約2秒です。Kokoroの日本語音声を後から合成し、読み上げが長い場合は映像を繰り返します。リップシンクには対応していません。
OpenAI gpt-ossのエージェント育成では、指示・知識・お手本を版として保存し、応答の評価・修正から次の版を作ります。重みを変更しない方式です。Ollamaとモデルは別途導入してください。20bはRAM16GB以上が目安です。

更新は右上「更新」→「最新版を確認する」→「更新版を取得する」。
新規インストールは `DeeL-Pyess-Setup-v0.1.6-Windows-x64.exe` を使用します。保存済みデータは引き継ぎます。

実AnimateDiffで10ステップの動画LoRA学習と継続学習を行い、選択した完成版から720p・AAC日本語音声付きMP4を生成しました。開発環境では学習が各約5分、生成が約25分。一般のノートPCでは処理時間がさらに長くなる場合があります。
実gpt-oss:20bで育成前後の応答を比較し、知識の反映、評価からの次版作成、その版での応答を確認しました。モデル実行プロセスの最大RSSは約13.1GiBで、OSや他アプリのメモリは別途必要です。
Windowsでは、基盤モデルの追加で起動待ちが終わらなくなる不具合も修正しました。

非日本語のWindows環境でも、日本語名のモデル情報・音声設定をUTF-8で保存・再読込するよう修正しました。

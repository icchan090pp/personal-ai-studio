# DeeL Pyess v0.1.7 — 学習済みの画風と、画像・動画の関連学習

「おすすめ設定」でアニメ風・VTuber風・水彩・写真風を選べます。画像は学習済みのDreamShaper 8、動画はAnimateDiff＋DreamShaper 8をCPU用の設定で選択します。RAM 16GB以上が目安です。Tiny-SD・Small-SDなど、既存の基盤も引き続き選択できます。

「関連画像／関連動画を自動で探し、一緒に学習する」を追加しました。投稿データをPC内のBLIP・CLIPで解析し、検索語だけをWikimedia Commonsへ送信します。候補を見た目・説明・重複で絞り、1回最大3件（設定1〜5件）を実際のLoRA学習へ追加します。動画は複数フレームを比較し、短いクリップを学習します。公開元が提供する小さい配信用動画を優先し、容量上限と取得制限を守ります。

元の投稿データを検索の手がかりにし続けます。追加データは元データ以下の件数・半分の重みで学習します。出典・類似度・取得結果を表示し、不要な画像や動画は次の学習から除外できます。検索の失敗や候補なしは画面に表示し、元データで学習を続けます。以前の完成モデルは残ります。

画像・動画の学習相談にThink・Researchを追加しました。Thinkは現在の学習状況から改善案を考えます。Researchは公式の学習資料と公開素材の検索結果を参照し、出典付きで提案します。ローカルOllamaとgpt-ossが必要です。重いAI処理は学習・生成と順番に実行し、提案は確認・編集してから学習指示へ反映します。

初回に画像解析モデル約1.6GBと選択した基盤を取得します。生成する作品の品質はお手本・設定によって変わり、最適な学習や全作品・全VTuberの網羅を保証しません。30億枚の新規学習を実施した更新ではありません。動画は標準256px・約2秒を出発点とし、高解像度は拡大出力です。音声は別モデルで合成します。

更新：アプリ右上「更新」から確認・取得するか、`DeeL-Pyess-Setup-v0.1.7-Windows-x64.exe` を実行してください。保存済みのデータと完成モデルを引き継ぎます。


PC内で使うReal-ESRGANの高精細化・ノイズ除去も追加しました。アニメ用／写真用の公開モデルをCPUで使用し、2倍・4倍に拡大します。入力は長辺1024pxまで、出力は長辺4096pxまで。動画は先頭フレームの静止画として仕上げます。

学習・生成のプロンプト付近に画像追加の「＋」を表示しました。学習側ではお手本の投稿、生成側では下絵・参考画像を使い、選択中の画像モデルと育成版で生成します。変更の強さを調整し、同じ参考画像・プロンプト・シードで育成前後を比較できます。追加画像を確認・解除でき、参考画像を学習データへ自動で入れることはありません。

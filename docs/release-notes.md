# DeeL Pyess v0.1.1 — Preview

画像・動画・音声学習の問題が起きた際、処理を停止してリセットできます。投稿データと完成モデルを保持します。
SDXL 1.0・SSD-1B・PixArt Sigma・LTX-Videoの公開ウェイト生成、OpenAI gpt-oss-20b/120bのローカルOllama学習相談、
画像・動画共通のウルトラ（生成200ステップ）を追加。画像は対応モデルの1024pxネイティブ生成と、モデル別ガイダンスを使用します。

黒と青のPC／スマートフォンUI、別々の学習・生成チャット、探索・投稿・グループ分け、6種類の画像学習、
CogVideoX動画LoRA、実験用効果音学習、パラメータ棒グラフ、実践8コース。
指定サイズ2100×2050・720p〜UHD 4Kは生成後の拡大・余白調整です。

製品試験は100件、5回連続で全件合格。実際の学習プロセス停止、PC/モバイル操作、4モデルの呼び出し契約・実ファイル出力を含みます。
追加公開モデルの重みを用いる実GPU推論とgpt-oss実推論は未検証のためPreviewです。GPU品質・全機種のエラーゼロを保証しません。
追加4モデルは生成専用。gpt-ossは文章用・別途Ollama取得、音声は短い効果音の実験モデルです。
モデルは同梱せず初回取得。料金不要の公開ウェイトでも各配布元のライセンス条件が適用されます。

Python 3.12/3.13が必要。ZIPを展開してWindowsはInstall-Windows.bat、Linuxはinstall.shを実行します。
CUDA GPU利用時はGPU依存を選択。スマートフォンはGPU PCと同じWi-FiでStart-Phoneから接続します。

公開音声モデルとしてAudioLDM2 Large（非商用）とKokoro日本語読み上げ、OpenVoice V2参照声質を追加。
動画の音声抽出とサイト音声収集から学習データへ。「ゆっくり／高め」などの対応指示を声質プロフィールに保存します。
Kokoroの実モデル・OpenVoiceの実モデルでCPU生成、特徴抽出、声質変換、高さ調整を確認。
アプリの実ワーカーでもWAV生成・投稿・声質取り込み・指示反映・音声ダウンロードまで確認しました。
声質取り込みは特徴抽出で、全重みの追加学習ではありません。モデルや録音ごとに再現度が変わります。

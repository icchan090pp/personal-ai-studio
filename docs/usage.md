# DeeL Pyess 操作ガイド

## インストールと接続

Python 3.12または3.13をインストールして、配布ZIPを展開します。
Windowsは `Install-Windows.bat` でGPU版を選び、`Start-Windows.bat` で起動。
Linuxは `./install.sh --gpu`、`./start.sh`。GPUなしでも投稿・整理・サイト収集・コースを使用できます。
ブラウザを閉じても処理は続きます。起動ターミナルのCtrl+Cで終了してください。

スマートフォンはGPUパソコンと同じ信頼できるWi-Fiへ接続します。
パソコンで `Start-Phone.bat` または `./start-phone.sh` を起動し、表示された
`http://パソコンのIP:8000/connect?token=接続コード` をスマートフォンのブラウザで開きます。
PCのファイアウォールはプライベートネットワークのポート8000を許可します。
接続コードは起動ごとに変わります。配布・公開せず、インターネットにポートを公開しないでください。
計算・モデル・データはパソコンに置かれます。スマートフォン単体でGPU学習するアプリではありません。

## データの準備

1. 「新しいモデル」で名前と英数字のトリガーワードを登録。
2. エクスプローラー・フォルダ選択・ドラッグでPNG/JPEG/WebPを投稿。画像は3枚以上。
3. 画像の説明とグループを編集。変更は自動保存。
4. 「サイト・検索から自動収集する」で公開URLまたはWikimedia Commons検索を指定。
   指定サイトは同じホスト内の最大3ページ、キーワードはファイル名やalt属性に照合。
   1回10画像まで。動画は最大3フレームと、対応する短いクリップを保存。
   出典を記録し、失敗は収集欄へ表示。利用できるデータを選んでください。
   サイトのJavaScript実行・ログイン・アクセス制限回避・インターネット全体の検索はしません。
5. 「動画・音声の学習データを追加」でMP4/WebMまたはWAV/MP3を投稿。
   動画・音声は各1秒以上・1ファイル50MB・合計30件。先頭約6秒を使用。
   動画は1920×1080以下。動画をH.264に変換、音声を16kHzモノラルWAVに変換します。

## 学習チャットと学習

学習チャットへ `watercolor texture, soft colors` のような短い英語表現を送信します。
送信指示は次の学習説明に追加され、履歴は選択中のモデルに保存されます。
文章からコードを生成・実行する対話LLMではありません。SDの長い説明はトークン上限で省略されます。
音声の条件は説明文のハッシュIDを使う実験的方式で、自由文の意味理解はしません。

学習対象を画像・動画・音声から選び、グループ・学習率・ランク・ステップを調整して
「学習をはじめる」を押します。画像は6方式：通常、半教師あり、スタイル、RWR、生成テスト、写し学習。
半教師ありはBLIPで未編集画像の説明を補完し、仮ラベルの重みを0.5にします。
RWRは生成画像を1〜5で評価した後、既存LoRAを継続学習します。PPO/DDPOではありません。
生成テストは学習後に試作画像を出力します。動画・音声は通常・写し・スタイルの説明を使った学習に対応。

動画はCogVideoX I2Vの時間方向を含むattention LoRAを学習し、次の動画生成で自動適用。
音声は小型の波形拡散モデルを学習。短い環境音・効果音の実験用で、音質は限定的です。
会話音声の読み上げ・声の再現・音楽の高品質生成には対応しません。
音声生成プロンプトには学習時の説明と同じ文章を使ってください。

棒グラフは実測の損失・勾配L2・学習重みL2を約10ステップごとに表示します。
画像・動画ではLoRA重み、音声では全学習重みのL2です。最大12点を表示します。
失敗時はアクティビティと `data/jobs/ジョブID/worker.log` を確認してください。

## 生成チャット

生成チャットは学習チャットと別の履歴です。
画像モデルの学習完了後、トリガーワードを含むプロンプトで画像を生成。
動画は完成画像を元として選び、動きの指示を入力。音声モデルの学習後に「音声付き」を選べます。
音声は動画と同じ長さへ書き出し、AACとしてMP4へ付加します。映像との同期は学習しません。

両生成モデルにノーマル20／パワー35／エクセレント50生成ステップを適用。
「深考」は品質プリセット名で、言語モデルの推論ではありません。
標準画像512×512、動画720×480・49フレーム・8fps・約6.125秒。
720p、1080p、1440p、4KはLanczos拡大と余白調整による16:9出力です。指定サイズ2100×2050も選択できます。
4Kは3840×2160のファイルを出せますが、ネイティブ4Kの精細さを保証しません。

設定マークから共通ルール・除外条件を保存・リセットできます。初期ユーザールールは空。
これは共通生成プロンプトの設定で、基盤モデルの性質を消す機能ではありません。

## 開発コース

8つの実践コースを自由に選び、理論→実習→比較→振り返りを進めます。
進捗と実験ノートはモデルごとに保存。配布用LoRAと比較結果を成果物にまとめます。

Linuxで実行権限がない場合：`chmod +x install.sh start.sh start-phone.sh` を実行してください。

## 追加の公開ウェイトとウルトラ

生成画面の「生成モデル」で追加4モデルを選択できます。学習済みLoRAがなくても使えます。
画像は SDXL 1.0、SSD-1B、PixArt Sigma（1024×1024のネイティブ生成）、動画は LTX-Video
（テキストから768×512、49フレーム・8fps）です。追加モデルへSD 1.5／CogVideoXのLoRAを流用しません。
追加モデルの独自学習・動画音声合成は未対応。モデル配布元の改変で壊れないよう取得コミットを固定します。
ウェイトは同梱せず初回に取得するので、十分な空きディスクとインターネット接続が必要です。
SDXL／PixArtはOpenRAIL++、SSD-1BはApache-2.0、LTXは独自ライセンスです。
ダウンロード費用は不要ですが、各モデルの利用条件・商用条件は配布元を確認してください。
必要メモリの目安はSDXL 12〜16GB、SSD 8〜12GB、PixArt 12〜24GB、LTX 16〜24GB。
CPUへのオフロードを使用しますが、必要量は設定・実機に依存し未実測です。

ウルトラ（レベル200）は画像・動画の生成を200ステップにし、学習の初期設定は5000ステップです。
追加モデルは各アーキテクチャ向けのガイダンス値（SDXL/SSD 5、PixArt 4.5、LTX 3）を使います。
大きなモデルとネイティブ解像度で表現力を高める設定ですが、プロンプト・モデル・シードによって結果は変わり、
200ステップが50ステップより常に良いとは限りません。同一シードで結果を比べてモデルを選択してください。
4Kと2100×2050は生成後のLanczos拡大・余白調整です。

## OpenAI gpt-ossで相談

無料の[Ollama](https://ollama.com/download)をGPUパソコンへインストールし、
`ollama pull gpt-oss:20b`（大容量PCなら `ollama pull gpt-oss:120b`）を実行します。
同じパソコンのOllamaを起動したまま、学習チャットの「OpenAI gpt-ossで学習相談・プロンプト作成」を開き、
モデルと質問を選択します。回答を確認してから、学習指示・生成プロンプトへ必要な部分を自分で貼り付けます。
アプリはPC内の127.0.0.1:11434だけへ接続し、API課金はありません。スマートフォンからもPC経由で利用できます。
20bは約16GB以上、120bは約80GB以上のRAM/VRAMが目安。Apache-2.0の文章用公開ウェイトです。
本アプリでgpt-oss自体の追加学習は行いません。ウルトラ／エクセレントではOllamaの推論深度highを使います。
Ollamaが未起動・未ダウンロードの場合、取得コマンドを案内して停止します。

## 学習の停止とリセット

学習画面の「学習を停止・リセット」で、そのプロジェクトの画像・動画・音声学習の待機・実行・失敗状態を解除します。
実行中の処理と子プロセスを停止し、GPU処理が終了してから再実行できます。エラー表示と進捗をリセットします。
投稿済み画像・動画・音声、説明、グループ、指示、完成したモデル、生成作品は保持します。
リセットした処理は「リセット済み」と記録し、未完成モデルを生成に使いません。他プロジェクト・生成処理は対象外です。
設定のルールを空にするボタンとは別の操作です。

## 公開音声モデル・人の声・指示で調整

Windowsのインストーラーは「3」でGPU・日本語読み上げ・声質機能をまとめて入れられます。
Linuxは `./install.sh --gpu --voice`。既存環境は `python install.py --gpu --voice`。
OpenVoiceのソースはMIT・固定コミットをチェックサム確認して取得し、Python 3.12対応の依存セットで組み込みます。
モデルの重みは初回取得。Kokoroの日本語辞書はコンパイル不要のライブラリを利用します。

生成対象の「音声」を選び、音声モデルを選択します。AudioLDM2 Largeは効果音・環境音を
英語の指示から生成（約6秒、16kHz）。**CC-BY-NC-SA-4.0で非商用利用に限定**されます。
Kokoro 82Mは日本語文章を読み上げます（24kHz・最大30秒、Apache-2.0）。
OpenVoice V2は声質の特徴を取り込み・反映します（MIT）。モデルごとの役割と再現性は異なります。
試作音声はプレーヤーで聴き、WAVとして保存できます。動画を選び「音声付き」で公開音声モデルも付加できます。
音声は動画の長さに合わせて終了し、口の動きとの同期・会話演技は行いません。
AudioLDM2はCUDA GPUが必要。Kokoroと声質の取り込みはCPUでも可能ですが時間がかかります。

自分の声や、利用許可を得た声優などの録音を3件以上追加して、学習対象「人の声」を選択します。
背景音の少ない録音で、同じ話者のグループを選んでください。
OpenVoiceの凍結モデルで話者特徴を抽出し平均して保存する方式です。モデル全体の追加学習や
声優の演技・感情を学ぶ機能ではありません。学習ステップ・学習率・LoRAランクは特徴抽出に使いません。

学習チャットへ「ゆっくり、高めの声」「速く、低め」のように指示して保存できます。
対応語句から読み上げ速度（0.8/1.0/1.2）と声の高さ（-2/0/+2半音）を決め、声質プロフィールへ保存します。
英語 slow/fast/higher pitch/lower pitch も対応。相反する指示・対応しない表現は標準値です。
自由な文章の演技指示を意味理解してモデル重みを変更する方式ではありません。
生成時はKokoroと「取り込んだ声質を読み上げに反映」を選択。声質変換後、高さを調整します。
同じ文章をKokoroのみ／声質反映ありで試聴し、録音・指示を変えて再取り込みできます。
再現度はモデル、録音、言語によって変わり、特定の人と同じ声になる保証はありません。

動画投稿時の「動画の音声も学習データへ取り込む」をチェックすると、動画と抽出音声を別々に保存します。
音声トラックがない動画は、このチェックを外して投稿してください。
サイト収集で「音声・動画の音声トラック」または「画像・動画・音声すべて」を選択すると、
公開音声や動画の音声をデコードし、出典を記録して学習データへ追加します。
3件以上集め、音声（実験用拡散）・声質特徴・動画LoRAのいずれかの学習対象を選びます。
サイトはHTTPメディアの収集で、ログイン・JavaScript配信・DRM・配信サービスのダウンロードには対応しません。

公開音声モデル自体の重みの追加学習は未対応。既存の実験用音声拡散は指示＋説明を条件IDにして最適化します。
短い効果音の学習用で、人の自然な発話はKokoro＋OpenVoiceで扱います。

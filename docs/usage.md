# DeeL Pyess 操作ガイド

## インストールと接続

Python 3.12または3.13をインストールして、配布ZIPを展開します。
Windowsは `Install-Windows.bat` でGPU版を選び、`Start-Windows.bat` で起動。
Linuxは `./install.sh --gpu`、`./start.sh`。GPUなしでも投稿・整理・サイト収集・コースを使用できます。
ブラウザを閉じても処理は続きます。起動ターミナルのCtrl+Cで終了してください。

スマートフォンはGPUパソコンと同じ信頼できるWi-Fiへ接続します。
パソコンで `Start-Phone.bat` または `./start-phone.sh` を起動し、表示された
`http://パソコンのIP:8000/connect?token=接続コード` をスマートフォンのブラウザで開きます。
PCのファイアウォールはプライベートネットワークのポート8000を許可します。
接続コードは起動ごとに変わります。配布・公開せず、インターネットにポートを公開しないでください。
計算・モデル・データはパソコンに置かれます。スマートフォン単体でGPU学習するアプリではありません。

## データの準備

1. 「新しいモデル」で名前と英数字のトリガーワードを登録。
2. エクスプローラー・フォルダ選択・ドラッグでPNG/JPEG/WebPを投稿。画像は3枚以上。
3. 画像の説明とグループを編集。変更は自動保存。
4. 「サイト・検索から自動収集する」で公開URLまたはWikimedia Commons検索を指定。
   指定サイトは同じホスト内の最大3ページ、キーワードはファイル名やalt属性に照合。
   1回10画像まで。動画は最大3フレームと、対応する短いクリップを保存。
   出典を記録し、失敗は収集欄へ表示。利用できるデータを選んでください。
   サイトのJavaScript実行・ログイン・アクセス制限回避・インターネット全体の検索はしません。
5. 「動画・音声の学習データを追加」でMP4/WebMまたはWAV/MP3を投稿。
   動画・音声は各1秒以上・1ファイル50MB・合計30件。先頭約6秒を使用。
   動画は1920×1080以下。動画をH.264に変換、音声を16kHzモノラルWAVに変換します。

## 学習チャットと学習

学習チャットへ `watercolor texture, soft colors` のような短い英語表現を送信します。
送信指示は次の学習説明に追加され、履歴は選択中のモデルに保存されます。
文章からコードを生成・実行する対話LLMではありません。SDの長い説明はトークン上限で省略されます。
音声の条件は説明文のハッシュIDを使う実験的方式で、自由文の意味理解はしません。

学習対象を画像・動画・音声から選び、グループ・学習率・ランク・ステップを調整して
「学習をはじめる」を押します。画像は6方式：通常、半教師あり、スタイル、RWR、生成テスト、写し学習。
半教師ありはBLIPで未編集画像の説明を補完し、仮ラベルの重みを0.5にします。
RWRは生成画像を1〜5で評価した後、既存LoRAを継続学習します。PPO/DDPOではありません。
生成テストは学習後に試作画像を出力します。動画・音声は通常・写し・スタイルの説明を使った学習に対応。

動画はCogVideoX I2Vの時間方向を含むattention LoRAを学習し、次の動画生成で自動適用。
音声は小型の波形拡散モデルを学習。短い環境音・効果音の実験用で、音質は限定的です。
会話音声の読み上げ・声の再現・音楽の高品質生成には対応しません。
音声生成プロンプトには学習時の説明と同じ文章を使ってください。

棒グラフは実測の損失・勾配L2・学習重みL2を約10ステップごとに表示します。
画像・動画ではLoRA重み、音声では全学習重みのL2です。最大12点を表示します。
失敗時はアクティビティと `data/jobs/ジョブID/worker.log` を確認してください。

## 生成チャット

生成チャットは学習チャットと別の履歴です。
画像モデルの学習完了後、トリガーワードを含むプロンプトで画像を生成。
動画は完成画像を元として選び、動きの指示を入力。音声モデルの学習後に「音声付き」を選べます。
音声は動画と同じ長さへ書き出し、AACとしてMP4へ付加します。映像との同期は学習しません。

両生成モデルにノーマル20／パワー35／エクセレント50生成ステップを適用。
「深考」は品質プリセット名で、言語モデルの推論ではありません。
標準画像512×512、動画720×480・49フレーム・8fps・約6.125秒。
720p、1080p、1440p、4KはLanczos拡大と余白調整による16:9出力です。指定サイズ2100×2050も選択できます。
4Kは3840×2160のファイルを出せますが、ネイティブ4Kの精細さを保証しません。

設定マークから共通ルール・除外条件を保存・リセットできます。初期ユーザールールは空。
これは共通生成プロンプトの設定で、基盤モデルの性質を消す機能ではありません。

## 開発コース

8つの実践コースを自由に選び、理論→実習→比較→振り返りを進めます。
進捗と実験ノートはモデルごとに保存。配布用LoRAと比較結果を成果物にまとめます。

Linuxで実行権限がない場合：`chmod +x install.sh start.sh start-phone.sh` を実行してください。
